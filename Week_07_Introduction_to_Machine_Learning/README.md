# Introduction to Machine Learning

## Overview

This week introduced the standard machine learning workflow:

**Split → Train → Predict → Evaluate**

Two supervised machine learning projects were completed:

1. Linear Regression for a regression problem.
2. Logistic Regression for a binary classification problem.

## Learning Objectives Covered

- Machine learning workflow
- Train-test splitting
- Linear Regression
- Logistic Regression
- Regression evaluation metrics
- Classification evaluation metrics
- Model comparison
- Plain-language interpretation

## Regression Project

The scikit-learn Diabetes dataset was used for the regression project.

Linear Regression was trained to predict a continuous target.

Evaluation metrics:

- MAE
- MSE
- RMSE
- R²

An actual-versus-predicted visualization was also created.

## Classification Project

The scikit-learn Breast Cancer dataset was used for the classification project.

Logistic Regression was trained for binary classification.

Evaluation metrics:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

## Main Learning

Regression and classification are different machine learning problems and therefore require different evaluation metrics.

The notebook demonstrates the complete basic workflow:

**Split → Train → Predict → Evaluate**
