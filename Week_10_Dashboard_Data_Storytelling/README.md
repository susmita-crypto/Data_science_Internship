\# Dashboards and Data Storytelling



\## Purpose



This Week 10 project focuses on presenting data findings clearly to a non-technical audience using Power BI.



The dashboard uses the cleaned Titanic dataset and presents descriptive survival patterns across different passenger groups.



\## Tool Used



\- Power BI Desktop



\## Dataset



The dashboard uses the cleaned Titanic dataset prepared during the earlier data-wrangling work.



The dataset contains passenger information including:



\- Passenger class

\- Sex

\- Age

\- Fare

\- Family size

\- Survival status



A dashboard-specific CSV file was prepared as:



`titanic\_dashboard\_data.csv`



\## Business Question



> What factors were associated with passenger survival on the Titanic?



\## Dashboard Components



The dashboard contains five key metrics/charts:



1\. \*\*Total Passengers\*\*

&#x20;  - 891 passengers



2\. \*\*Overall Survival Rate\*\*

&#x20;  - 38.4%



3\. \*\*Survival Rate by Gender\*\*

&#x20;  - Compares survival rates between female and male passengers.



4\. \*\*Survival Rate by Passenger Class\*\*

&#x20;  - Compares survival rates across first, second, and third class.



5\. \*\*Survival Rate by Age Group\*\*

&#x20;  - Compares survival rates across different age groups.



A gender filter is also included to allow the dashboard user to interact with the data.



\## Key Findings



The dashboard shows clear differences in survival rates across passenger groups. Female passengers had a higher survival rate than male passengers. Survival rates also differed by passenger class, with first-class passengers showing a higher rate than second- and third-class passengers.



Survival rates also varied across age groups. These patterns show that survival was not the same across all passenger groups.



The dashboard is descriptive and shows patterns in the Titanic dataset. The observed differences should not be interpreted as proof that a particular factor caused the differences in survival.



\## Data Storytelling



The dashboard was designed for a non-technical audience by using simple charts, summary metrics, a clear business question, and a short written explanation of the main findings.

\## Limitations



\- The Titanic dataset is a historical dataset and does not represent a current business.

\- The dashboard presents descriptive patterns rather than causal conclusions.

\- The dataset contains historical passenger information and should be interpreted in its original context.

\- The dashboard is intended as an educational data storytelling exercise.
