# Exploratory Data Analysis and Visualization

## Objective

This week focused on Exploratory Data Analysis (EDA) and data visualization using Matplotlib and Seaborn.

The goal was to identify distributions, relationships, trends, and meaningful patterns in the Titanic dataset cleaned during Week 3.

## Dataset

The analysis uses the cleaned Titanic dataset created during Week 3.

The cleaned dataset contains:

- 891 rows
- 16 columns
- No missing values
- No duplicate rows

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

The EDA included:

1. Dataset inspection
2. Distribution analysis
3. Histograms
4. Box plots
5. Scatter plots
6. Survival analysis
7. Categorical variable analysis
8. Correlation analysis
9. Correlation heatmap
10. Written interpretation of visualizations

## Key Insights

The analysis identified several important patterns:

- Female passengers had a higher survival rate than male passengers.
- First-class passengers had better survival outcomes than passengers in lower classes.
- Fare values varied considerably across passenger classes.
- Most passengers were concentrated among younger and middle-aged adults.
- Family-size analysis showed that travelling alone and travelling with small family groups were common patterns.
